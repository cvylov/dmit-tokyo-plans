## 为什么选日本服务器，要先想清楚线路

日本机房物理上离中国大陆近，广东到东京 CN2 GIA 实测延迟大约 60-80ms，比洛杉矶机房普遍低 100ms 以上。但"日本服务器"这个搜索词背后真正决定体验的，不是机房位置，而是**回程线路**。

DMIT 在东京把产品拆成了三个网络系列：

- **Premium（TYO.Pro）**：回程 CN2 GIA，去程电信 CN2 GIA + 联通 AS9929 + 移动 CMI，1Gbps 端口。这是 DMIT 的顶配大陆优化线路，针对晚高峰做了专门保障，适合直接面向国内用户的工作负载。
- **Eyeball（TYO.EB）**：三网回程走 CMI，去程电信/联通 CTG GIA + 移动 CMI。介于 Pro 和 T1 之间的折中方案，移动用户体验尤其好。但目前官网已下架这个系列，实际能买到的概率很低，下文不再展开。
- **Tier 1（TYO.T1）**：国际互联，无大陆专项优化。电信/联通走 NTT，有时会绕美走 Lumen；移动走 CMI，体验尚可。10Gbps 大端口、流量超出限速不停机是它的卖点。

选错系列的后果很直接：用 T1 跑面向国内用户的服务，晚高峰可能会卡得怀疑人生；用 Pro 跑一个只面向日本本土或东南亚的项目，相当于花钱买了一堆用不上的大陆优化带宽。

## 不同线路实际表现怎么样

**Premium（Pro）的延迟和稳定性**

Pro 系列走 CN2 GIA 双向，根据多个独立测评和社区反馈，广东电信到东京 Pro 实测延迟约 64ms，联通约 52ms，移动约 54ms，晚高峰丢包率能控制在 0.1% 以下。这个表现放在亚太 CN2 GIA 产品里属于正常水平，比一般走 163 骨干的日本 VPS 在高峰期稳定得多。

Pro 系列一个长期存在的问题是**经常缺货**。DMIT 不超售的策略让服务器表现稳定，但代价就是补货不可预测。如果看到 Pro 有货且符合你的需求，建议直接下手，不要等。

**Tier 1（T1）的定位**

T1 没有大陆专项优化，电信和联通晚高峰可能会绕美走 Lumen，延迟拉到 200ms 以上不奇怪。但移动用户走 CMI，体验反而还行。如果你大部分流量来自移动网络，T1 其实是能用、甚至体验不错的。

T1 真正的甜区在**大带宽 + 不停机**。10Gbps 端口、超流量限速到 100Mbps-1Gbps 不等（按套餐递增），跑大流量备份、内容分发、跨境数据传输这类场景，性价比远高于 Pro。日本流媒体解锁也没问题——T1 实测可以解锁 U-NEXT、Lemino、FOD、Radiko 等日本本地服务，原生日本 IP 的属性没有因为线路是国际而受影响。

**关于 Netflix 等主流平台**

Netflix、Disney+ 这类平台对 IP 的封禁策略是动态的，任何 VPS 都不能保证长期稳定解锁。建议购买后用实际 IP 测试，或参考 DMIT 社区的最新反馈。

## IP 更换和退款政策

**IP 被墙怎么办**

DMIT 的标准政策是每 15 天可以免费更换一次 IP。超过这个频率，每次 $5。通过特定促销活动购买的套餐可能有不同限制（比如某次三年付活动把 IP 更换限制为每 30 天一次，且每次收费 $5），购买前需要看清楚活动条款。

Pro 系列 IP 偶尔会被标记或封锁，这是 CN2 GIA 产品的通病。可以在 checkout 时加 $1 购买一个 IP 保证标识，提升拿到可用 IP 的概率。

**退款窗口**

3 天内无理由全额退款（流量使用 ≤ 30GB），或 30 天内按剩余价值退款。退款到账户余额不扣手续费，原路退回可能产生一定费用。续费订单、余额支付、同系列第三次以上退款不适用退款政策。

3 天的测试窗口够用来跑延迟测试和稳定性验证。如果你在纠结 Pro 还是 T1，可以先用 T1 月付跑几天，确认线路方向后再决定要不要升级 Pro。
